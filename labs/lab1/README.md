To run the program, you must first compile the WeatherAnalyzer.java file, then run it using "java WeatherAnalyzer.java <filename>". 
After running the program, the user is prompted to input a number between 1 to 6, each number corresponding to a given column in the CSV file. 
For example, if the user were to input '1', then the program will display the statistics of the HighTempF column of the file; the same logic applying to inputs 2-5. The program will continue to prompt the user unless they were to input 6, then the program will exit. 
However, if the user were to input a number out of the 1-6 range, then a message will appear prompting the user to enter a number from that range.
